# 論文の増減は、実務での価値の増減ではない — レコメンド研究7年分を数えて考えたこと

「グラフニューラルネットワークの研究、最近あまり見ないよね」

こういう話は、たいてい印象論で語られて終わる。実際に数えてみたらどうなのか。
そして仮に本当に減っていたとして、それは**その技術が使えなくなったこと**を
意味するのか。

DBLP から主要6会議（RecSys / SIGIR / KDD / WWW / WSDM / CIKM）の
2019年から2025年までの採択論文を集め、推薦関連のフル論文2,108本を
トピック別に分類して数えた。arXiv のプレプリント7,740本も見ている。

この記事は、その結果と、そこから考えたことの話である。

先に立場を書いておくと、**私は2019年から2021年に大学でレコメンドシステムを
研究していたが、いまは実務でレコメンドを触っているわけではない**。
事業会社のデータアナリストとして数字は扱っているが、推薦システムを本番で
運用している立場ではない。後半の考察は現場報告ではなく、
「この数字をアナリストとして読むとこう考える」という仮説として読んでほしい。

分析スクリプトと集計結果、判定の全件一覧は GitHub に置いてある。
技術的な詳細（トラックの切り出し方、分類辞書、限界の全リスト）は
Zenn の技術版に書いた。

## 数え方を先に

結論の前に、何を数えたかを開示しておく。この手の集計は前提で結論が動くので。

- **主研究トラックのフル論文だけ**を数えた。デモ、チュートリアル、
  Doctoral Symposium、産業界トラック、Resource / Reproducibility トラックは分離した
- **すべて比率**で見ている。会議の採択数自体が増えているからだ
  （KDD のフル論文は2019年174本 → 2025年551本）。件数で見ると全部が伸びて見える
- **分類はタイトルのみ**。DBLP はアブストラクトを持たない。
  だから新しい語彙（`LLM`、`prompt`）は拾いやすく、
  同じ概念を古い言葉で書いた論文は取りこぼしやすい。
  **増えている軸は多めに、減っている軸は少なめに出る**バイアスが構造的にある

抽出したフル論文数は公表採択数と突き合わせてある。
SIGIR 2019年=84本、2020年=147本、2021年=151本、WWW 2019年=225本、
RecSys 2019年=36本は公表値と完全に一致した。

## 数えた結果

![](../reports/figures/fig1_period_change.png)

| トピック | 2019–2021 | 2023–2025 | 変化 |
|---|---:|---:|---:|
| LLM-based | 0.3% | 15.2% | **+14.9pt** |
| Cold-start / Federated | 11.1% | 16.3% | +5.2pt |
| Multimodal | 3.6% | 8.3% | +4.7pt |
| Sequential / Session-based | 17.3% | 21.7% | +4.4pt |
| Causal / Debiasing | 7.6% | 8.2% | +0.6pt |
| Fairness / Explainability | 9.4% | 8.4% | −1.0pt |
| Reinforcement Learning | 8.2% | 6.9% | −1.3pt |
| Graph / GNN | 21.8% | 16.6% | **−5.2pt** |

Graph / GNN は確かに減っていた。5.2ポイント。
そしてもっと面白いのは、**いつ減ったか**のほうだった。

![](../reports/figures/fig2_yearly_small_multiples.png)

年ごとに並べると、2019年から2023年までは19〜23%で安定している。
2023年はむしろ22.5%と高い。**急落したのは2024年**で、14.0%まで落ちた。

そして LLM-based が立ち上がったのも、まったく同じ2024年だった。
2023年時点ではまだ2.2%。それが2024年に17.8%、2025年に24.5%になる。

ChatGPT の公開は2022年11月なので、**査読済み会議録に現れるまでに約1年半**
かかったことになる。投稿締切、査読、開催のサイクルを1周する分だけ、
研究の主題転換は遅れて可視化される。

つまり Graph / GNN は緩やかに衰退したのではない。
**LLM が入ってきたのと同じ年に、入れ替わるように反転した。**

## LLM は既存研究を「吸収」しなかった

![](../reports/figures/fig4_llm_cooccurrence.png)

2023〜2025年の推薦フル論文1,140本のうち、LLM-based は173本。
この173本が他のトピックをどれだけ併せて扱っているかを見ると：

| | LLM-based 論文 | それ以外 |
|---|---:|---:|
| Graph / GNN も扱う | **1.7%** | 19.2% |
| Causal / Debiasing も扱う | 1.2% | 9.4% |
| Sequential も扱う | 15.0% | 22.9% |
| **他の7軸をひとつも扱わない** | **58.4%** | 20.6% |

LLM 論文の6割近くが、既存の7軸のいずれにも触れていない。
とくに Graph / GNN との共起は1.7%で、非LLM論文の19.2%に対して一桁少ない。

新しい技術が来たとき、既存研究と融合して発展することもあれば、
別のコミュニティが別の問題を解き始めることもある。
少なくとも論文のタイトルを見るかぎり、推薦研究で起きたのは**後者**に近い。

## ここからが本題：論文の増減は、実務での価値の増減ではない

さて、Graph / GNN のシェアが5ポイント落ちた。
これをどう読むべきか。

論文シェアが測っているのは、**研究コミュニティの関心の配分**である。
**実務での有用性**ではない。この2つは似ているようで、まったく別のものだ。

研究の世界には「新規性がなければ通らない」という強い制約がある。
確立された手法は、どれだけ現場で効いていても、論文としては書きにくくなる。
逆に言えば、**論文シェアの減少は「陳腐化」ではなく「成熟」のサインでもありうる**。

私はこの数字を、こう読んでいる。

### Graph / GNN：論文から消えたことと、現場から消えたことは別

GNN ベースの推薦は、レイテンシと計算コストの制約が厳しい環境でも
現実的に運用しうる規模に収まる。
グラフ構造そのもの（ユーザー-アイテムの相互作用、ソーシャル関係、
知識グラフ）は、生成AIが来ても消えていない。

論文としてのシェアが落ちたのは、**手法として一区切りついてネタでなくなった**
という読み方のほうが自然だと考えている。
これは後で述べる LLM との対比で効いてくる。

### LLM-based：論文の勢いと、本番投入の距離

一方で、arXiv を見ると別の絵が出てくる。

![](../reports/figures/fig6_conference_vs_preprint.png)

プレプリントは会議録より一貫して先行していて、
**2026年（8月まで）は推薦関連プレプリントの55%が LLM 関連**である。
半分以上だ。

ただ、事業に載せることを考えると、論文の勢いとは別の検討がいくつも要る。

まず推論のレイテンシとコスト。推薦の応答は数十ミリ秒のオーダーで返す必要が
ある場面が多く、候補生成からランキングまでを LLM の推論で通すのは、
少なくとも素直な形では厳しいだろうと考えられる。
オフライン推論で埋め込みや特徴量を作っておく、
候補生成は従来手法で行いランキングの一部にだけ使う、といった
**部分適用**のほうが、導入を検討するなら現実的な入り口に見える。

もうひとつは、**論文で報告される改善が、実際のオンライン指標にどれだけ乗るか**。
これは LLM に限った話ではないが、新しい手法ほどオフライン評価での改善幅が
大きく報告されやすい。そしてこれは、次の論点に直結する。

### Causal / Debiasing：論文では地味だが、実務の課題そのもの

この軸は7年間ほぼ横ばいだった（+0.6pt）。2021年に11.3%でピークを打ち、
以後7〜9%で推移している。派手さがない。

だが扱っている問題は、**オフライン評価とオンライン効果の乖離**という、
推薦システムを事業で運用するかぎり必ずぶつかる課題そのものだ。

ログは既存の推薦システムが露出させたものだけを記録している。
そのログでオフライン評価をすれば、既存システムに似た挙動をするモデルが
高く評価されやすい。露出バイアス、人気バイアス、選択バイアス — 
この軸の主題は、まさにその構造を扱っている。

論文シェアが伸びていないのは、この問題が解決したからではないと考えている。
**手法として一区切りついて、新規性を主張しにくくなった**だけではないか。

だとすれば、実務で推薦の改善に取り組むなら、
最新の LLM 手法を追うより、この領域の既存研究を読んで
オフライン評価の設計に反映するほうが費用対効果は高いかもしれない。

もっとも、これは論文数からの推測であって、私が実際に効果を測って
確かめたわけではない。

## おまけ：情報収集の設計に使えそうな話

査読済み会議録には**1年半ほどの遅れ**がある。
「いま会議で流行っているもの」を追いかけると、
研究コミュニティの関心からは1周遅れた状態を見ていることになる。

一方で arXiv は先行しているぶん玉石混交で、
査読を通っていない主張をそのまま業務判断の根拠にはできない。

だとすると、**arXiv で方向を掴み、会議録で選別する**という
役割分担が素直なのだと思う。何が来ているかは arXiv で見て、
何が生き残ったかは会議録で確かめる。

今回の集計でいえば、**Multimodal 推薦がちょうどその位置にある**。
arXiv では加速しているが、会議録にはまだ十分現れていない。

## まとめ

数えてわかったこと：

1. **分岐点は2023年ではなく2024年。** ChatGPT 公開から会議録に現れるまで約1年半
2. **Graph / GNN の反転も同じ2024年。** 緩やかな衰退ではなく、同時に起きた入れ替わり
3. **LLM 研究は既存テーマと融合していない。** 6割近くが他の軸に触れず、
   Graph / GNN との共起は1.7%
4. **Fairness / Explainability、Reinforcement Learning、Causal / Debiasing は
   7年間ほぼ横ばい。** 関心が集中していないことと、問題が解決したことは別
5. **プレプリントは会議録より1年以上先行。** いま arXiv では推薦研究の半分以上が LLM 関連

そして繰り返しになるが、**論文の増減は研究コミュニティの関心の配分であって、
実務での価値の増減ではない**。減っているテーマが役に立たなくなったわけでも、
増えているテーマがすぐ使えるわけでもない。
その2つを混同しないことが、この数字のいちばん有用な使い方だと思っている。

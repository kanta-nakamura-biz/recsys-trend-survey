# レコメンド研究の潮流は7年で何が変わったか — 主要6会議の論文2,108本を数えた

## この記事について

2019〜2021年、私は大学でレコメンドシステムの研究をしていた。その後就職し、生成AIが来た。研究の潮流がどう変わったのか、印象論ではなく数字で確かめたくなり、DBLPから主要6会議の採択論文を集めて分類・集計した。

- **対象**: RecSys / SIGIR / KDD / WWW / WSDM / CIKM、2019〜2025年
- **件数**: 推薦関連のフル論文 2,108 本（arXiv プレプリント 7,740 本も補助的に参照）
- **公開**: 分析スクリプト、集計結果、判定の全件一覧を GitHub で公開

> 🔗 リポジトリ: https://github.com/kanta-nakamura-biz/recsys-trend-survey

念のため、レコメンド研究の潮流をまとめたサーベイ論文自体はすでにいくつも存在する。学術的な新規性はここでは主張しない（目をつぶってほしい）。あくまで自分の目で実データを取得・検証してみた、という個人の調査として読んでもらえればと思う。

---

## 数え方

- **主研究トラックのフル論文のみ**を対象（デモ、チュートリアル、Doctoral Symposium、産業界トラック、Resource / Reproducibility は除外）
- **すべて比率で見る**：会議の採択数自体が増えているため（KDD のフル論文は2019年174本→2025年551本）。件数だけ見ると全テーマが伸びて見えてしまう
- **検証済み**：抽出したフル論文数を公表採択数と突合。SIGIR 2019=84本、2020=147本、2021=151本、WWW 2019=225本、RecSys 2019=36本は完全一致。一致しない年（RecSys 2023・2024）も原因を特定し、除外しても結論は変わらないことを確認済み
- **限界**：DBLPはアブストラクトを持たないため分類はタイトルのみ。新しい語彙（`LLM`, `prompt`）を拾いやすく、増えている軸は多め・減っている軸は少なめに出るバイアスが構造的にある
- **分類手法**：キーワード辞書による一次分類（1,228本）＋残り880本をLLMでラベリング。ラベルはリポジトリに含めてあるのでAPIキーなしで再現可能

## 結果1：7年で何が増え、何が減ったか

![](../reports/figures/fig1_period_change.png)

| トピック | 2019–2021 | 2023–2025 | 変化 |
|---|---:|---:|---:|
| LLM-based | 0.3% | 15.2% | **+14.9pt** |
| Cold-start / Federated | 11.1% | 16.3% | +5.2pt |
| Multimodal | 3.6% | 8.3% | +4.7pt |
| Sequential / Session-based | 17.3% | 21.7% | +4.4pt |
| Causal / Debiasing | 7.6% | 8.2% | +0.6pt |
| Fairness / Explainability | 9.4% | 8.4% | −1.0pt |
| Reinforcement Learning | 8.2% | 6.9% | −1.3pt |
| Graph / GNN | 21.8% | 16.6% | **−5.2pt** |

（1論文が複数軸に属しうるため合計は100%を超える）

LLMが跳ね、グラフが落ちた。ただし期間平均は変化がいつ起きたかを隠してしまう。

---

## 結果2：分岐点は2023年ではなく、2024年だった

![](../reports/figures/fig2_yearly_small_multiples.png)

- LLM論文は2023年時点でまだ2.2%。2024年に17.8%、2025年に24.5%へ不連続に立ち上がる。ChatGPT公開（2022年11月）から約1年半のラグ
- Graph / GNNは2019〜2023年まで19〜23%で安定（2023年は22.5%）していたが、2024年に14.0%へ急落。**LLMが立ち上がったのと同じ年に反転**している
- 一方、Fairness / Explainability（8〜11%で横ばい）とReinforcement Learningは7年間ほぼ動かず。Causal / Debiasingは2021年に11.3%でピークを打った後7〜9%で推移

---

## 結果3：LLMは他のテーマを「吸収」したのか

![](../reports/figures/fig4_llm_cooccurrence.png)

2023–2025年の推薦フル論文1,140本中、LLM論文は173本。他軸との共起は：

| | LLM論文 | それ以外 |
|---|---:|---:|
| Graph / GNNも扱う | 1.7% | 19.2% |
| Causal / Debiasingも扱う | 1.2% | 9.4% |
| Sequentialも扱う | 15.0% | 22.9% |
| 他7軸をひとつも扱わない | **58.4%** | 20.6% |

答えは、ほぼ独立。融合ではなく置き換えに近い（ただしタイトルベース判定のため、GNNと組み合わせた論文がLLM側しかタイトルに書かない可能性は残る）。

---

## 結果4：プレプリントは会議より1年以上先を走っている

![](../reports/figures/fig6_conference_vs_preprint.png)

- LLM関連は会議録が2.2%だった2023年時点で、arXivではすでに16%。2026年（8月まで）は55%に達する
- Graph / GNNは逆にarXivで2021年をピークに一貫して減少。会議録側はこれを2〜3年遅れで追う
- MultimodalがarXiv側で加速中。次に会議録で目立ってくる可能性がある

---

## 著者を追う：GNNの人はLLMに移ったのか

DBLPの著者pidで同一著者を追跡した。**移動はしている。ただし主因ではない。**

| 2019–23年の群 | 2024–25も活動 | うちLLM論文 |
|---|---:|---:|
| Graph / GNN論文あり | 352人 | 41.8% |
| Graph / GNN論文なし | 540人 | 32.4% |

差は9.4ptにとどまる。主因は新規参入だった：

| 2024–25年のLLM著者795人の出自 | 割合 |
|---|---:|
| 新規参入（2019–23年に本データで論文なし） | **59.5%** |
| 既存だがGNN以外 | 22.0% |
| 元GNN勢 | 18.5% |

さらに元GNN勢はGNNを捨てていない。24–25年の論文でLLM-basedが全体平均より高い（27.0% vs 24.1%）のと同時に、Graph / GNNも全体平均より高い（15.4% vs 12.8%）。乗り換えではなく上乗せに近い。

（限界：本データの6会議でしか著者を追えないため、「新規参入」には他分野からの流入と別会議で活動していた著者の両方が含まれる）

## 実数で見る：減ったトピックはひとつも無い

| トピック | 2019–21 | 2023–25 | 倍率 |
|---|---:|---:|---:|
| LLM-based | 2 | 173 | **86.5倍** |
| Multimodal | 23 | 94 | 4.09倍 |
| Cold-start / Federated | 72 | 186 | 2.58倍 |
| Sequential / Session-based | 112 | 247 | 2.21倍 |
| Causal / Debiasing | 49 | 93 | 1.90倍 |
| Fairness / Explainability | 61 | 96 | 1.57倍 |
| Reinforcement Learning | 53 | 79 | 1.49倍 |
| Graph / GNN | 141 | 189 | **1.34倍** |
| （推薦論文計） | 647 | 1,140 | 1.76倍 |

8軸すべて実数では増加。推薦論文全体が1.76倍になった分、伸びが遅い軸がシェアを落としただけで、Graph / GNNの−5.2ptは縮小ではなく減速。ただし直近2年（2023年81本→2025年53本）は実数でも減っている。

---

## まとめ

シェアの増減と実数の増減が逆方向を向いていたのが、今回の一番の収穫だった。Graph / GNNは5.2pt落ちているのに本数は増えている。LLMの急伸も、既存著者の乗り換えではなく新規参入が主因だった。論文の増減は研究コミュニティの関心の配分であって、実務での価値の増減ではない。

集計スクリプト、判定の全件一覧、限界の詳細はGitHubに置いてある。分類の妥当性を確認したい方は `reports/classification_audit.md` を見てほしい。

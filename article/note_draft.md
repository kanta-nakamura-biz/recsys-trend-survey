# 社会人になっても専門分野を追い続けられる時代になっていた — AIエージェントと論文2,108本を数えた話

自分が昔やっていた研究分野、いま どうなってるんだろうと思ったことはないだろうか。

僕は2019年から2021年、大学でレコメンドシステムの研究をしていた。グラフ構造を使って研究者を推薦する手法を、ランダムウォークとコサイン類似度で解くようなことをやっていた（GNNではなく、ニューラルネット抜きの古典的なグラフアルゴリズムのほう）。その後就職してデータアナリストになり、研究とは縁のない生活を送っていたんだけど、生成AIが来てから、ふとこの問いが頭に浮かぶようになった。

特にここ数年は、どの分野も生成AIの影響を受けて構造が変わっていてもおかしくない時期だと思う。自分の専門だった分野に限らず、離れた業界や昔のテーマについて「いま何が起きてるんだっけ」と気になっている人は、たぶん僕だけじゃないはずだ。

ただ、ちゃんと調べようとすると話は変わる。文献をまとめて傾向を掴む作業は本来ものすごく時間がかかる。うちには1歳と0歳の子どもがいて、平日にPCへ向かえる時間はほぼゼロだ。学生時代のように腰を据える時間は、もう自分の生活には存在しない。だから「LLMばっかりになったんでしょ」くらいの印象論で済ませて終わり、というのがこれまでの相場だったと思う。

## AIエージェントに、サーベイの作業自体をやらせてみた

DBLPから主要6会議（RecSys / SIGIR / KDD / WWW / WSDM / CIKM）の2019〜2025年の採択論文を集めて、推薦に関するフル論文2,108本をトピック別に分類する。arXivのプレプリント7,740本も同じ方法で見る。著者IDを使って同じ人物を年をまたいで追跡する。

これを、AIエージェント（Claude Codeのようなコーディングエージェント）と対話しながら一気にやった。データ取得のスクリプトを書かせて、分類ロジックを一緒に詰めて、集計と作図とレポート化まで、リポジトリごと組んでもらった。使えた時間は週末に子どもたちが昼寝している2〜3時間だけ。それでも数週間でリポジトリが動くところまで終わった。学生時代に一人でやろうとしたら数ヶ月はかかっていたと思う。まとまった時間が取れなくても、切れ切れの数時間を積み上げれば形になる、というのが正直な感覚だった（もちろん月額の課金は発生するけど、いまの自分にとって時間のほうがよほど希少なので、割の良い取引だと思っている）。

速さだけでなく、検証の精度も上げやすかったのは意外だった。一人でやると大体端折る裏取り作業——抽出したフル論文数を各会議の公表採択数と突き合わせる検証——も、AIエージェントに任せてついでにできた。SIGIR 2019年=84本、2020年=147本、2021年=151本、WWW 2019年=225本、RecSys 2019年=36本は、公表値と完全に一致している。一致しない年も原因を特定した上で、除外した場合の感度分析まで出せた。

もちろん分類はタイトルだけに基づいているし、キーワード辞書は新しい語彙を拾いやすいというバイアスもある。この辺りの限界は隠さずに技術版に書いた。AIエージェントを使ったからといって万能になるわけではなく、「検証込みで速くできる」というのが正確なところだと思う。

## で、肝心の中身：僕がいた分野に何が起きていたか

**分岐点は2023年じゃなくて2024年だった。** LLMを使った推薦の論文は、2023年の時点でまだ2.2%。それが2024年に17.8%、2025年に24.5%になる。ChatGPTの公開が2022年11月なので、査読済みの会議録に出てくるまで約1年半かかった計算だ。

**僕がいた「グラフ」の括りのテーマも、同じ年に反転していた。** 正確には僕がやっていたのはGNNではなくランダムウォークを使った手法だったけど、Graph / GNN という同じカテゴリで見ると、2019〜2023年まで19〜23%で安定していたシェアが、2024年に14.0%まで落ちる。じわじわではなく、この1年で起きている。

**じゃあGNNの人たちはLLMに移ったのか、著者を追ってみた。** 移動はしている。でも主因ではなかった。2024〜25年のLLM論文の著者795人のうち、以前この6会議にいなかった新規参入者が59.5%。GNNからの乗り換え（18.5%）より、外から入ってきた人の数のほうがずっと多い。しかも元GNN勢はGNNを書くのをやめておらず、平均より多く両方書いている。

**そして実数で数え直すと、減ったテーマがひとつもなかった。** シェアで見るとGNNは5.2ポイント減っているが、本数では141本から189本に増えている。8トピック全部が実数では増えていて、推薦論文全体が1.76倍に膨らんだ分、伸びが遅かったテーマがシェアを落としているだけだった。

自分がいたグラフ系のテーマが「終わった」のかと思って調べ始めたら、実は誰も辞めていなくて、単に新しい人がどっと増えただけだった、というオチだ。論文の増減は研究コミュニティの関心の配分であって、実務での価値の増減ではない、というのが今回の分析の結論だ。

## この話、自分の専門分野だけじゃないと思う

「自分がいた分野、今どうなってるんだろう」という好奇心は、研究者出身の人に限らない。前の職種、離れた業界、昔ハマっていた技術領域——気になっているものは誰にでもあるはずだ。これまでネックだった「時間さえあれば」が、AIエージェントのおかげでかなり低い壁になったと思う。

気になる分野がある人は、まとまった時間がなくても一度試してみてほしい。ぜひ自分の専門分野で試した結果も教えてほしい。畑違いの分野でどんな変化が起きているのか、単純に他人の結果として読んでみたい。
